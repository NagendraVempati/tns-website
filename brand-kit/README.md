# TNS Infrasolutions stationery

Three separate print PDFs:

Business cards: 90 x 50 mm finished size, with 3 mm bleed on all sides (PDF page 96 x 56 mm). TrimBox and BleedBox are embedded. Print front and back at 100% scale on opposite sides of the same stock, matching their top edges; ask the printer to confirm duplex orientation. Do not use Fit to page. All content is safely inside the trim area.

Letterhead: A4, 210 x 297 mm, with a clear writing area. Print at 100% scale.

Artwork uses vector shapes and embedded fonts in the PDFs. Color is RGB; the printer can convert to its chosen press/paper profile. These are standard PDFs, not certified PDF/X files. Editable SVG versions are in editable/ (Arial is required when editing text). The logo is a clean vector rendition of the supplied navy-and-green reference, not a photographic crop.
